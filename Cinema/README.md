# Cinema Booking System
A desktop application for managing movie tickets and snacks with a premium UI.

## Features
### User Function
- Seat booking with clear interface
- Snack purchase 
- Secure payment system
- Order history viewing
- Personal account management

### Staff & Admin Function
- Movie management
   1. Create new Movie
   2. Edit Movie
  3. Delete Movie
- Showtime Schedule Management
  1. Create new Schedule
  2. Edit Schedule
  3. Delete Schedule
- F&B Stock Management
  1. Add new snack or drink
  2. Check the stock of each item
  3. Replenish stock
- Sales Report Generation
  1. Generate report about number of tickets and snacks sold and the total revenue of each category. The top-selling items will be shown.

## Getting Started
1. Open the project `Cinema` in your IDE.
2. Run `Cinema.java` to start the application.

## Build With
